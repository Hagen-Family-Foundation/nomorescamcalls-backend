# Block 3 — Caller Response SOP

## Purpose

Block 3 gathers and evaluates caller-response evidence.

Block 3 does not make assumptions about the caller. It processes only evidence produced during the current call.

Every caller receives the same two-prompt process.

## Trigger

Receive the completed Block 2 Evidence Box.

## Standard Operating Procedure

1. Play Evidence Prompt 1.
2. Record the caller’s response.
3. Transcribe the recorded response.
4. Submit the transcript to the Response Evaluator.
5. Store the Prompt 1 evidence:

   * audio recording reference
   * transcript
   * evaluator result
6. Play Evidence Prompt 2.
7. Record the caller’s response.
8. Transcribe the recorded response.
9. Submit the transcript to the Response Evaluator.
10. Store the Prompt 2 evidence:

    * audio recording reference
    * transcript
    * evaluator result
11. Apply the approved Block 3 deduction rules.
12. Determine the caller’s current standing.
13. Execute IPQS only when the current standing is between 76 and 85 inclusive.
14. Store any IPQS evidence and resulting deductions.
15. Determine the standing after all Block 3 deductions.
16. Produce the completed Block 3 Evidence Box.
17. Pass the completed Evidence Box to Block 4.

## Response Evaluator Contract

The Response Evaluator receives one transcript.

### Input

* transcript

### Output

* usable name: yes or no
* usable reason: yes or no

The Response Evaluator performs no deductions, scoring, standing calculation, routing, disposition, IPQS execution, or recommendations.

It returns only whether the transcript contains a usable name and a usable reason.

The transcript remains part of the preserved evidence and does not need to be recreated or summarized by the evaluator.

## Empty or Unusable Transcript

When a transcript is empty or contains no usable response:

* usable name is no
* usable reason is no
* the Response Evaluator does not need to be called when the absence of a transcript is already known

The approved Block 3 deduction rules are then applied normally.

## Block 3 Deduction Responsibility

The Response Evaluator identifies facts only.

Block 3 owns all deductions resulting from those facts.

Current approved caller-response deductions are:

* unusable or missing name: 15 points
* unusable or missing reason: 15 points

The rules are applied independently to each evidence prompt.

A prompt may therefore produce:

* 0 points of deduction
* 15 points of deduction
* 30 points of deduction

Because every caller receives two evidence prompts, caller-response deductions may total up to 60 points.

## IPQS Rule

IPQS is conditional.

IPQS executes only when the caller’s standing after the standard Block 3 caller-response deductions is between 76 and 85 inclusive.

IPQS does not execute when standing is:

* 86 through 100
* 75 or below

Any IPQS findings and deductions must be stored separately from the evidence gathered through the two caller-response prompts.

## Evidence Stored

Every call produces the same Block 3 evidence structure.

### Evidence Prompt 1

* audio recording reference
* transcript
* usable name result
* usable reason result
* deductions

### Evidence Prompt 2

* audio recording reference
* transcript
* usable name result
* usable reason result
* deductions

### Block 3 Results

* total Block 3 deductions
* standing before IPQS
* whether IPQS was executed
* IPQS findings, if executed
* IPQS deductions, if any
* standing after Block 3

## Evidence Library

The completed Block 3 evidence is preserved for the Evidence Library.

The Evidence Library receives:

* Prompt 1 audio
* Prompt 1 transcript
* Prompt 1 evaluation
* Prompt 2 audio
* Prompt 2 transcript
* Prompt 2 evaluation
* Block 3 deductions
* standing before IPQS
* IPQS evidence, if executed
* final standing after Block 3

Every call record must use the same evidence structure, regardless of the caller’s standing or final disposition.

## Boundaries

Block 3 does not:

* use prior calls to judge the current call
* create caller reputation
* make allow or divert decisions
* determine the final call disposition
* perform offline research
* alter Evidence Library history
* allow the Response Evaluator to control scoring
* allow the Response Evaluator to control routing

Block 3 gathers evidence, applies its approved deduction rules, determines current standing, conditionally executes IPQS, and passes the completed Evidence Box to Block 4.

## Change Control

Prompt wording, voice, pause timing, transcription provider, Response Evaluator provider, and model selection may change without altering this SOP, provided the process and evaluator contract remain unchanged.

Any change to the two-prompt process, deduction rules, IPQS range, evidence structure, or Block 3 responsibilities requires an approved SOP update before code is changed.
