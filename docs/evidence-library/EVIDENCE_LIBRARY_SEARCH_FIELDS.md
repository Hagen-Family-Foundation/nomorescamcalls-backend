# NoMoreScamCalls Evidence Library Search Fields

## Purpose

This document defines every searchable field contained within the Evidence Library.

Every completed call produces one Call Record.

Every Call Record exposes the same searchable structure.

Some fields may contain no value depending upon how the call concluded.

The searchable structure never changes.

Every individual field may be searched independently or combined with any other searchable field.

# Search

Every field listed in this document is independently searchable.

Searches may combine any number of fields.

Searches may combine Caller and Subscriber fields.

Searches return every Call Record matching the requested criteria.

The Evidence Library never modifies the stored Call Record as the result of a search.
